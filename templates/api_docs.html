API Documentation

Welcome to the EmotionSense AI API! You can send text data to our API endpoint and get sentiment analysis results in JSON format.

📍 Endpoint

POST /api/analyze

📥 Request Body (JSON)

{
    "text": "I love this product!",
    "analysis_type": "basic"
}

📤 Response Example

{
    "sentiment": "Positive",
    "confidence": 95,
    "explanation": "The text expresses strong positive emotions."
}

✅ You can use tools like Postman or curl to test the API.
