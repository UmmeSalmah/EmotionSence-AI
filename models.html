API Endpoints

POST /api/analyze

Analyze sentiment of provided text using Google Gemini AI

Request Body
{
"text": "string (required, max 5000 characters)",
"analysis_type": "string (optional, default: 'basic')"
}
Analysis Types
  • basic - Quick sentiment classification with confidence score
  • detailed - Emotional breakdown with key phrases
  • comparative - Multi-approach analysis comparison
Response (Basic Analysis)
{
"success": true,
"result": {
"sentiment": "Positive",
"confidence": 85,
"explanation": "The text expresses clear satisfaction..."
},
"analysis_type": "basic",
"timestamp": "2024-01-15T10:30:00Z"
}

Error Handling

Common Error Responses

{

}

Error Codes
  • 400 Bad Request - Invalid input data
  • 413 Payload Too Large - Text exceeds limit
  • 429 Too Many Requests - Rate limit exceeded
  • 500 Internal Server Error - AI service error

Code Examples

Python
import requests

url = "https://your-domain.com/api/analyze"
data = {
"text": "I love this product!",
"analysis_type": "basic"
}

response = requests.post(url, json=data)
result = response.json()

print(f"Sentiment: {result['result']['sentiment']}")
print(f"Confidence: {result['result']['confidence']}%")
JavaScript
const analyzeText = async (text) => {
const response = await fetch('/api/analyze', {
method: 'POST',
headers: {
'Content-Type': 'application/json'
},
body: JSON.stringify({
text: text,
analysis_type: 'basic'
})
});

const result = await response.json();
console.log(result);
};
PHP
$url = 'https://your-domain.com/api/analyze';

'analysis_type' => 'basic'
);

$options = array(
'http' => array(
'header' => "Content-type: application/json\r\n",
'method' => 'POST',
'content' => json_encode($data)
)
);

$context = stream_context_create($options);
$result = file_get_contents($url, false, $context);
$response = json_decode($result, true);
